# LSS-Autoalarm
Script zur Alarmierung incl. Fahrzeugauswahl
Ihr könnt bei diesem Script auswählen ab welcher Mindestanzahl an Credits ein Einsatz automatisch im Verband freigegeben werden soll.
Weiterhin habt ihr die Möglichkeit euch ein Fahrzeug fetzulegen, welche bei der Freigabe alarmiert wird, so dass euch die Credits des Einsatz sicher sind
In der Auswahlliste werden alle Fahrzeugtypen des LSS aufgelisten. Die Liste ist zweigeteilt. Im oberen Abschnitt werden die Fahrzeuge gelistet die ihr selbst bestitzt. Hinter den Fahrzeugen steht die Anzahl der verfügbareb Fahrzeuge.
Weiterhin könnt ihr noch einstellen, in welchen zeitlichen Abständen das Script eure Alarmliste überprüft um neu hinzugekommene Einsätze zu alarmieren.
Letztendlich könnt ihr noch einen Text für das Rückmeldesystem schreiben, welcher dann auch automatisch im Einsatz geschrieben steht.
